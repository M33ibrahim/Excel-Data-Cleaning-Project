# Fleet Inventory Data Cleaning | Microsoft Excel

A data preparation portfolio project using the Montgomery County Fleet Equipment Inventory dataset.

## Purpose

Prepare inventory records for consistent grouping and downstream analysis by addressing duplicates, inconsistent department names, spelling, and whitespace.

## Project file

[Montgomery_Fleet_Equipment_Inventory_FA_PART_1_START (1).xlsx](<Montgomery_Fleet_Equipment_Inventory_FA_PART_1_START (1).xlsx>)

This is the workbook available in the repository. Its filename contains `START`; a separate before-and-after pair is not included, so the cleaning impact cannot be quantified from file names alone.

## Documented cleaning tasks

The original project describes:

- Removing duplicate records.
- Correcting spelling inconsistencies.
- Combining department names with Flash Fill.
- Removing unnecessary whitespace and columns.
- Saving the data in Excel format.

## Review and quality checks

1. Download a copy and inspect the worksheets and column headings in Excel.
2. Define which columns identify a duplicate before removing records.
3. Check that department labels use a consistent format.
4. Reconcile row counts before and after each cleaning operation.
5. Retain an untouched source copy when reproducing the workflow.

These are review steps; this README does not claim that every check has already passed.

## Dataset

[Montgomery County Fleet Equipment Inventory](https://data.montgomerycountymd.gov/Government/Fleet-Equipment-Inventory/93vc-wpdr)

The public source can change over time. Record the download date when reproducing the project.
